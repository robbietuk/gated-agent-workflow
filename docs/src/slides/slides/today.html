Where we are today

Today

I am the glue between every step

  • Research, plan, implement and review are each triggered by hand.
  • Brainstorming happens inside planning chats.
  • I carry context from one chat to the next.
  • Review depends on how much time is left.

Target

I approve; the agent runs the loop

  • I write the spec and approve the design and outline.
  • The agent builds slice by slice, with tests as the gate.
  • Reviews run automatically, with hard iteration limits.
  • I read the final code. Plan problems come back to me.
The goal isn’t less engineering judgement; it’s spending it where it matters. I stay in charge of what we build and of the final code; the agent does the repetitive loop in between.
