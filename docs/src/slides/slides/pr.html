Escalate · /wf-escalate: revert, replan, log it. Fired by a hit limit, a review, the show-me or your code read.

PR description

Summary, req IDs covered, test evidence, decisions from the log, known risks.

Branch review

Reviewers scaled to the diff: 1 for a few lines, up to 12 for a big branch. Max 2 fix rounds.

Your code read

Read the code, not just the plan. Approve or send it back. The agent never merges.

Slice reviews see pieces; the branch review is the one check that sees how the slices fit together. Teams that tried skipping the human code read went back to it.
