Design doc

About 200 lines: current and end state, patterns, decisions, open questions, risks.

Slice outline

Thin vertical slices, each with req IDs, acceptance criteria and tests to write.

You approve

The agent asks about gaps. Approve, revise, or send it back to rework the design.

These two loops stay manual on purpose: this is where judgement pays off most. Short artifacts steer better than long plans. Make the first slice a thin end-to-end path so a wrong idea shows up early.
