The agent drafts questions

Questions the codebase must answer before anyone designs a solution.

Research stays neutral

A read-only researcher sees the questions only, never the spec, and returns facts with file and line references.

Research that knows the intended solution goes looking for evidence for it. Giving it only questions keeps the findings objective, which is why the spec never reaches the researcher.
