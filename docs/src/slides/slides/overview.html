Each command ends by asking whether to continue: stay in the same chat through planning, then start a new chat for the build and the PR, since every stage reads its inputs from files. Purple boxes are where a person decides; teal boxes run on their own. The dashed bar is the safety valve: plan problems always come back to a human, who reverts, replans and logs the decision.
