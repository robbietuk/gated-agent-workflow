What teams already doing this learned

Short artifacts steer better

A ~200-line design and a two-page outline beat an eight-page plan that drifts from the code.

Keep research objective

Research mixed with the intended solution loses its objectivity. Give it questions only.

Keep reading the code

Skipping code review “did not end well”. Reviewing the plan doesn’t prove the code matches it.

Revert and replan

When a run goes off track, a sharper plan and a re-run is often faster than patching.

Sources: HumanLayer, “Evolution from RPI to CRISPY” (via ZenML LLMOps database); Cursor, “Best practices for coding with agents” (Jan 2026).

Most tools have converged on the same phased shape: research, plan, implement. These four lessons are why our version has short design docs, question-only research, a mandatory code read, and a revert-and-replan escalation.
