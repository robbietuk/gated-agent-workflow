Gated agent workflow

Manual where you think. Agentic where it builds. You own the what; the agent owns the how; tests decide done.

YouAgentAgent drafts, you approve

1The flow

Start
/wf-start, /wf-research
Spec, questions, neutral research
›
Brainstorm loop
/wf-brainstorm
Options together → design doc · you approve
›
Planning loop
/wf-plan
Vertical slices, req IDs, tests · you approve
›
Per slice loop
/wf-build
Lock tests → implement → review → show-me
›
PR loop
/wf-pr
Description, branch review, your code read
/wf-escalate — any loop that isn’t converging: revert the slice, log the decision, go back to /wf-brainstorm (rethink) or /wf-plan (replan).

2The commands — each ends by asking to continue. Carry on in the same chat through planning; start a new chat for /wf-build and /wf-pr.

/wf-startYou + agent

Begin any feature, bug or small change.

Agent
Picks the track, creates .workflow/<date>-<slug>/, drafts factual questions for research.
You
Answer one question at a time; approve the spec (what, why, done, out of scope) or bug report.
Makes
spec.md or bug-report.md, questions.md, active.env
e.g. /wf-start add a configurable alarm-limit parameter
/wf-researchAgent

Facts about the code as it is today.

Agent
A read-only researcher answers questions.md only — it never sees the spec, so findings stay neutral.
You
Skim; flag anything that should change the spec.
Makes
research.md — facts with file:line, no opinions
Feature track; optional for small changes.
/wf-brainstormYou + agent

Agree the design before anything is built.

Agent
Plays back the ask, asks one question at a time, lays out 2–3 approaches with trade-offs.
You
Pick an approach; revise until you approve the design.
Makes
design.md (~200 lines: state, decisions, patterns, risks)
Also where escalations go to rethink.
/wf-planAgent drafts, you approve

Cut the design into thin vertical slices.

Agent
Each slice gets req IDs, acceptance criteria, tests to write, files, a risk flag. Asks about gaps.
You
Approve the outline, ask for changes, or say “rework” to go back to brainstorm.
Makes
outline.md — slice 1 is a thin end-to-end slice
Small change: one-slice outline straight after /wf-start.
/wf-buildAgent · you at show-me

Build one slice at a time, tests first.

Agent
Locks failing tests → implements (stop hook runs build + tests, max 5) → fast CI checks → fresh review sized to the slice (max 3 fixes) → show-me.
You
See it run with test evidence; approve → commit → next slice.
Makes
Commits, locked-tests.txt, slice status in outline.md
Re-run to resume; start a fresh chat if it gets long.
/wf-debugAgent · you approve fix

Bug track: no fix without a root cause.

Agent
Reproduces, locks a failing regression test, traces the root cause with evidence.
You
Approve root cause + fix, then /wf-build. A design flaw goes to brainstorm.
Makes
Investigation in bug-report.md, one-slice outline.md
Also usable mid-build when a failure’s cause isn’t obvious.
/wf-prAgent → you

Review the whole branch, then hand over.

Agent
Runs the repo’s CI checks (make ci, workflows); sizes the diff, then 1–12 lens reviewers (+ verifier) rank findings; fixes (max 2 rounds).
You
Read the code; approve or send back. You merge — the agent never does.
Makes
pr-description.md, fix(review) commits
Lenses: safety · concurrency · errors · compatibility · traceability
/wf-escalateYou decide

The planned exit when a loop won’t converge.

Fires
A limit hit, a plan issue from review, a wrong locked test, or you say no at show-me / code read.
Agent
Stops, proposes a revert (you confirm git commands), logs a dated decision.
Route
Rethink → /wf-brainstorm · Replan → /wf-plan
Run it yourself any time something feels off.

Pick a track

Feature — new behaviour worth designing
/wf-start → /wf-research → /wf-brainstorm → /wf-plan → /wf-build → /wf-pr

Bug — existing behaviour is wrong
/wf-start → /wf-debug → /wf-build → /wf-pr

Small change — ~1 hour, 1–3 files
/wf-start → /wf-plan → /wf-build → /wf-pr

Files: .workflow/<date>-<slug>/ · state in active.env

Limits — then escalate

Stop hook build + test runs5
Slice review → fix rounds3
PR fix → re-run rounds2
Planning rounds, then revisit spec3

Review depth scales with the diff: XS 1 light · S 1–2 · M 5 + verifier · L up to 12. High risk = one tier up. Tune in workflow.env

Never

  • Edit or loosen a locked test
  • Keep going past a limit
  • Let the agent merge, push or run destructive git
  • Fix a plan problem inside a build — escalate
